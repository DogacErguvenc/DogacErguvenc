## Selected work

### Retail product verification — Denker

The system compares a product selected on a retail scale with a camera image of the item being weighed, helping identify product-label mismatches. The project covered approximately 40 product classes and was tested in a store pilot.

My contributions included:

- Training image classification and embedding-based verification models with **PyTorch**, including **ResNet18**.
- Integrating local models into a **FastAPI** backend and supporting a hybrid workflow with offline inference and cloud vision APIs.
- Building workflows for image collection, training, embedding storage, batch evaluation, and live verification.
- Developing a **React / Tailwind CSS** management interface for product codes, operating modes, metrics, and image review, with **MongoDB** and **OpenCV** in the application stack.

[Read the project case study](https://github.com/DogacErguvenc/retail-product-verification-case-study)

A digital guest-guide project with a host dashboard, draft/published content, tenant-scoped SQL functions, revision checks, and shareable guide links and QR cards. It supports a local demo and a Supabase-backed cloud repository.

[Explore the source and local demo setup](https://github.com/DogacErguvenc/konak-misafir-rehberi)

### Santra — Flutter / Firebase

A mobile application I worked on for amateur-football teams and players. Development work covers authentication, team and player profiles, match-related flows, and notifications using **Flutter, Firebase, and Cloud Functions**.

[Explore the source and setup guide](https://github.com/DogacErguvenc/Santra-App)
